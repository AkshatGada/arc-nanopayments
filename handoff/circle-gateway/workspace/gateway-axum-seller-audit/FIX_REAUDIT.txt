Local fixes and independent re-audit — 16 October 2026

Status: both original P2 findings fixed locally. No push or PR.

Changes in gateway-axum-seller:
- New private src/transport.rs replaces the generic HTTP client for Gateway
  API calls while retaining the pinned x402-rs payment middleware unchanged.
- Reqwest redirect policy is none for every request. No same-origin or
  cross-origin redirects are followed, so authorizations are not forwarded.
- Automatic HTTP retries are explicitly disabled and the configured request
  timeout remains enforced.
- Every response must be HTTP 200 before JSON is parsed, including discovery,
  verification and settlement. HTTP 400/412 success-shaped bodies cannot be
  interpreted as acceptance. Error bodies and Location headers are not exposed.
- Discovery capabilities are captured at startup for this static-offer seller.
- Cargo.toml/Cargo.lock now declare reqwest directly; no upstream patches.
